# OccMed SQLite Local App

ระบบบันทึกข้อมูลคลินิกอาชีวเวชศาสตร์แบบ **Local Web App + SQLite Database**

ระบบนี้ออกแบบให้ใช้งานแบบ offline ในคอมพิวเตอร์เครื่องเดียว โดยเปิดผ่าน browser ที่ `http://127.0.0.1:8000` และเก็บข้อมูลในฐานข้อมูล SQLite ภายในเครื่อง

---

## 1. สิ่งที่ระบบนี้ทำได้

- บันทึกข้อมูลผู้ป่วยตาม HN
- บันทึกได้หลาย visit ต่อ HN
- ค้นหาประวัติแบบ EMR ด้วย HN
- เปิดดูรายละเอียดแต่ละ visit ได้
- บันทึกผลตรวจ เช่น ตา หู ปอด และ Return to work
- เก็บข้อมูลลง SQLite database ในเครื่อง ไม่ใช้ browser localStorage แล้ว
- Export / backup ข้อมูลได้

---

## 2. โครงสร้างไฟล์หลัก

หลังแตกไฟล์ zip จะเห็นโครงสร้างประมาณนี้

```text
occmed_sqlite_local_app/
├── app.py
├── requirements.txt
├── start_windows.bat
├── start_mac_linux.sh
├── README.md
├── templates/
│   └── index.html
├── data/
│   └── occmed.db          # ฐานข้อมูลจริง จะถูกสร้างอัตโนมัติเมื่อรันระบบ
└── backups/
```

ความหมายของไฟล์สำคัญ

| ไฟล์/โฟลเดอร์ | ความหมาย |
|---|---|
| `app.py` | Backend ของระบบ ใช้ Python Flask |
| `templates/index.html` | หน้าเว็บของระบบ |
| `requirements.txt` | รายชื่อ package ที่ต้องติดตั้ง |
| `start_windows.bat` | ไฟล์สำหรับเปิดระบบบน Windows |
| `data/occmed.db` | ฐานข้อมูล SQLite จริงของระบบ |
| `backups/` | โฟลเดอร์สำหรับเก็บไฟล์สำรองข้อมูล |

---

## 3. วิธีติดตั้งบนคอมพิวเตอร์ Windows เครื่องใหม่

### ขั้นที่ 1: ติดตั้ง Python

ถ้าเครื่องยังไม่มี Python ให้ติดตั้ง Python 3 ก่อน

1. ดาวน์โหลด Python จากเว็บไซต์ทางการ: `https://www.python.org/downloads/`
2. เปิดตัวติดตั้ง
3. ตอนติดตั้งให้ติ๊กช่องนี้ด้วย

```text
Add python.exe to PATH
```

4. กด Install

> ถ้าเครื่องเคยติดตั้ง Python แล้ว อาจข้ามขั้นตอนนี้ได้

---

### ขั้นที่ 2: ดาวน์โหลดไฟล์ระบบจาก GitHub

ถ้าเก็บระบบไว้บน GitHub แล้ว ให้ทำดังนี้

1. เข้า GitHub repository ของระบบ
2. กดปุ่ม **Code**
3. เลือก **Download ZIP**
4. แตกไฟล์ zip
5. จะได้โฟลเดอร์ เช่น

```text
occmed_sqlite_local_app
```

---

### ขั้นที่ 3: เปิดระบบ

เข้าไปในโฟลเดอร์ระบบ แล้วดับเบิลคลิกไฟล์นี้

```text
start_windows.bat
```

ครั้งแรกระบบจะทำสิ่งต่อไปนี้อัตโนมัติ

1. สร้าง virtual environment ชื่อ `.venv`
2. ติดตั้ง package ที่จำเป็น เช่น Flask
3. เปิด local server
4. เปิด browser ไปที่ระบบ

ถ้า browser ไม่เปิดเอง ให้เปิด Chrome แล้วเข้า URL นี้

```text
http://127.0.0.1:8000
```

---

## 4. วิธีใช้งานทุกครั้งหลังติดตั้งแล้ว

หลังติดตั้งครั้งแรกเสร็จแล้ว การเปิดใช้งานครั้งต่อไปทำแบบนี้

1. เข้าโฟลเดอร์ `occmed_sqlite_local_app`
2. ดับเบิลคลิก `start_windows.bat`
3. เปิด browser ที่

```text
http://127.0.0.1:8000
```

4. ใช้งานระบบตามปกติ
5. เมื่อเลิกใช้ ให้กลับไปที่หน้าต่างสีดำของ server แล้วกด

```text
Ctrl + C
```

จากนั้นปิดหน้าต่างได้

---

## 5. ข้อมูลถูกเก็บไว้ที่ไหน

ข้อมูลคนไข้จริงจะถูกเก็บในไฟล์นี้

```text
data/occmed.db
```

ไฟล์นี้คือฐานข้อมูลหลักของระบบ

**ห้ามลบไฟล์นี้ถ้าไม่ต้องการลบข้อมูลคนไข้ทั้งหมด**

---

## 6. วิธี backup ข้อมูล

วิธี backup ง่ายที่สุดคือ copy ไฟล์นี้เก็บไว้ในที่ปลอดภัย

```text
data/occmed.db
```

แนะนำให้ backup เป็นประจำ เช่น ทุกวันหรือทุกสัปดาห์

ตัวอย่างชื่อไฟล์ backup

```text
occmed_backup_2026-05-27.db
```

ตำแหน่งที่แนะนำให้เก็บ backup

- External hard drive
- Flash drive ที่เข้ารหัส
- Folder ที่มีการ backup อัตโนมัติ
- Cloud ส่วนตัวที่มีการป้องกันรหัสผ่าน

---

## 7. วิธีนำข้อมูลจริงไปใช้กับคอมอีกเครื่อง

ถ้าต้องการย้ายทั้งระบบพร้อมข้อมูลจริงไปอีกเครื่อง ให้ทำแบบนี้

### ที่เครื่องเดิม

Copy ไฟล์นี้ออกมา

```text
data/occmed.db
```

### ที่เครื่องใหม่

1. ติดตั้งระบบตามขั้นตอนปกติ
2. เข้าโฟลเดอร์ระบบใหม่
3. นำไฟล์ `occmed.db` จากเครื่องเดิมไปวางแทนที่ไฟล์ใน

```text
data/occmed.db
```

4. เปิดระบบด้วย `start_windows.bat`
5. ข้อมูลเดิมจะปรากฏในระบบ

เพื่อความปลอดภัยของข้อมูลผู้ป่วย ห้ามอัปโหลดไฟล์เหล่านี้ขึ้น GitHub

```text
data/occmed.db
backups/

*.sqlite
*.sqlite3
*.xls
*.xlsx

*.json
```

โดยเฉพาะไฟล์นี้

```text

```

เพราะเป็นฐานข้อมูลจริงของคนไข้

แนะนำให้ใช้ GitHub สำหรับเก็บ **ตัวโปรแกรมเปล่า ๆ** เท่านั้น ส่วนข้อมูลจริงให้ backup แยกต่างหาก

## 9. วิธีเตรียมไฟล์สำหรับอัป GitHub แบบปลอดภัย

ก่อนอัปขึ้น GitHub ให้ทำสำเนาโฟลเดอร์ระบบก่อน

ตัวอย่าง

```text
occmed_sqlite_local_app_clean
```

จากนั้นลบไฟล์ข้อมูลจริงออกจากโฟลเดอร์ clean

ให้ลบหรือไม่ใส่ไฟล์เหล่านี้

```text
data/occmed.db
backups/
ไฟล์ export ต่าง ๆ
```

จากนั้นค่อย zip โฟลเดอร์ clean แล้วอัปขึ้น GitHub

## 10. วิธี update ระบบโดยไม่ทำข้อมูลหาย

ถ้ามีเวอร์ชันใหม่ของระบบ และต้องการอัปเดตโดยเก็บข้อมูลเดิมไว้

1. ปิดระบบเก่าก่อน
2. Backup ไฟล์นี้ไว้ก่อนเสมอ

```text
data/occmed.db
```

3. ดาวน์โหลดระบบเวอร์ชันใหม่
4. แตกไฟล์ระบบใหม่
5. Copy ไฟล์ `occmed.db` เดิมไปวางในโฟลเดอร์ใหม่ที่

```text
data/occmed.db
```

6. เปิดระบบใหม่ด้วย `start_windows.bat`

## 11. การแก้ปัญหาเบื้องต้น

### 11.1 ดับเบิลคลิก `start_windows.bat` แล้วหน้าต่างปิดทันที

ให้ลองคลิกขวาที่ `start_windows.bat` แล้วเลือก

```text
Run as administrator
```

ถ้ายังไม่ได้ อาจเกิดจาก Python ยังไม่ถูกติดตั้ง หรือไม่ได้ติ๊ก `Add python.exe to PATH` ตอนติดตั้ง

---

### 11.2 ขึ้นว่า `py` หรือ `python` is not recognized

แปลว่า Windows หา Python ไม่เจอ

วิธีแก้

1. ติดตั้ง Python ใหม่
2. ตอนติดตั้งให้ติ๊ก

```text
Add python.exe to PATH
```

3. ปิด–เปิดเครื่องหนึ่งครั้ง
4. ลองดับเบิลคลิก `start_windows.bat` ใหม่

---

### 11.3 เปิด browser แล้วเข้าไม่ได้

ตรวจว่าหน้าต่าง server ยังเปิดอยู่หรือไม่

ถ้า server ปิดไปแล้ว ให้ดับเบิลคลิก `start_windows.bat` ใหม่

จากนั้นเข้า

```text
http://127.0.0.1:8000
```

---

### 11.4 ข้อมูลหายหลังย้ายโฟลเดอร์

ให้ตรวจว่าได้ copy ไฟล์นี้มาด้วยหรือไม่

```text
data/occmed.db
```

ถ้าไม่มีไฟล์นี้ ระบบจะสร้างฐานข้อมูลใหม่ที่ว่างเปล่า

---

### 11.5 เปิดระบบแล้วเหมือนเป็นข้อมูลว่าง

สาเหตุที่พบบ่อยคือเปิดจากโฟลเดอร์คนละอันกับที่มี database จริง

ให้ตรวจว่าไฟล์ `occmed.db` อยู่ในโฟลเดอร์นี้จริงหรือไม่

```text
occmed_sqlite_local_app/data/occmed.db
```
